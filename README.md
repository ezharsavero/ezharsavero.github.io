# ezharsavero.github.io

Personal portfolio of Ezhar Savero R. — System Engineer (Red Hat & Dell infrastructure), Jakarta.

Plain HTML, CSS and JavaScript. No build step: push to `main` and GitHub Pages serves `index.html`.

- `index.html` — all sections (home, about, skills, education, projects, experience, contact)
- `assets/css/style.css` — styles, light & dark theme
- `assets/js/script.js` — theme toggle, menu, typing effect, rack animation, project filter, contact form
- Contact form sends to ezhar.savero6@gmail.com via FormSubmit (formsubmit.co). The first submission triggers a one-time activation email.
